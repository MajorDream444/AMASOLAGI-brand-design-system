# AMA Solutions — Brand System

The source library for the AMA Solutions corporate identity: brand book, governance, approved logo files, design tokens, website components and imagery.

**Status: DRAFT library, packaged 31 October 2026.** The founder-approved badge is the master mark. Website tokens are exact values from the live amasolagi.com code. Brand (`brand-*`, `status-*`) colors and the proposed document fonts are provisional until sampled and approved.

> **No vector logo master exists yet.** Every badge, monogram and lockup file in this repository is a flattened raster image (PNG/JPG) on a light ground. The only SVGs are the *interim* website mark (a gold square with a triangle), which must not be used on new brand work. A faithful, founder-approved vectorization is the first open item — see `02-Logo-Masters/VECTOR-STATUS.md`.

## Rules that travel with the files

- Never redraw, recolor, add a ring to, or simplify the badge.
- The 144-worker idea is a founding symbol, not a deployed headcount.
- Label anything built on provisional tokens or proposed fonts as DRAFT.
- No credentials, legal clauses, banking or tax details in this repository.
