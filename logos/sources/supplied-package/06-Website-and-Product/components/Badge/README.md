# Badge
Small uppercase pill tag for status or category: `badge-gold` for highlighted status (often with a 6px gold dot), `badge-surface` for neutral tags.

- Consumer supplies: a `<span>` or `<div>` with `badge badge-gold` or `badge badge-surface` and a one-to-three-word label.
- Use for stage labels ("In development", "Concept") so readers can tell vision from live work.
- Static rendition of `.badge` in `src/app/globals.css`; the dot comes from the home hero.
