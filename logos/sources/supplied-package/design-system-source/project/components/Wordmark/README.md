# Wordmark
The AMA lockup: the gold mark, "AMA Solutions" in Inter 600 and a small "CORP" tag in JetBrains Mono, as used in Nav and Footer.

- Consumer supplies: a link to home wrapping the mark (`ama-mark.svg`, 28px), the `wordmark` text style in `text`, and the "Corp" tag in `label-mono`-like 10px mono, `text-dim`.
- The Footer variant drops the tag and writes "AMA Solutions Corp" in full.
- Gap between mark and name: 10px. Never recolor the mark or set the name in mono.
- This is the website's current lockup, built on the interim mark. For brand documents, decks and print use `ama-lockup-horizontal.png` (badge + "AMA / SOLUTIONS") from the Logos group instead.
- Static rendition of the lockup in `src/components/Nav.tsx`.
