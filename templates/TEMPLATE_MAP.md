# Reusable application templates - in_review
Catalogue: outcome / customer / inputs / deliverables / format / support / eligibility / confirmed price / CTA.
Bundle: included resource IDs / duplicates / access / fulfillment / price confirmation / CTA.
Proposal: client / problem / outcome / scope / exclusions / deliverables / owner / milestones / dependencies / fee placeholder / acceptance next step. No legal boilerplate.
Onboarding: goals / intake checklist / permissions / sources / owner / kickoff / consent / support.
Workspace: summary / next action / milestones / tasks / evidence / decisions / approvals / deliverables / activity / access.
Presentation: cover / agenda / problem / approach / evidence / scope / timeline / decision. 16:9 proposed.
Social: LinkedIn cover / product tile / case summary, editable copy and image-safe regions. Final platform crop checks pending.
Use application-proof.html for the first three visual examples. It is a static design shell; actions do not submit data.
