# Application templates

Build three representative examples before expanding:

1. Product catalogue section: individual products, bundles, descriptions, and clear next actions.
2. Consulting proposal page: scope, deliverables, responsibilities, schedule, commercial terms.
3. Client workspace overview: next steps, tasks, documents, workflow progress.

Then extend to booking, onboarding, presentations, social assets, and distribution as needed. Keep changing offer data editable. Use fictional example client data. All newly generated layouts remain draft until reviewed.
